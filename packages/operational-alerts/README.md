# @tasktwin/operational-alerts

Framework-independent, strict version 1 operational-alert contracts for
TaskTwin. The package derives severity and lifecycle, validates fixed templates
and typed action targets, routes active Workspace members, and creates stable
deduplication keys. It accepts no arbitrary title, body, URL, HTML, recipient
list, runtime value, secret, output, locator, browser error, or provider data.

The package has no NestJS, Prisma, React, Next.js, Playwright, database,
filesystem, notification SDK, or AI dependency. Persistence and asynchronous
delivery remain application responsibilities.
